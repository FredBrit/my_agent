# Скилл: Написание тестов

Используй, когда просят написать тесты или проверить функциональность.

## Правила
- Для FastAPI используй `pytest` и `httpx.AsyncClient` (или `TestClient`).
- Один тест = одна проверка (не пихай всё в один `def test_everything()`).
- Тесты должны быть изолированы (каждый создает свои данные).

## Алгоритм
1. Прочитай код, который нужно протестировать (`read_file`).
2. Определи сценарии: успешный ответ (200), ошибка валидации (422), не найдено (404).
3. Создай файл `tests/test_<module_name>.py`.
4. Если нужны фикстуры (например, тестовая БД), создай `tests/conftest.py`.
5. Установи зависимости: `install_package("pytest")`, `install_package("httpx")`.
6. Запусти: `run_command("python -m pytest tests/ -v")`.
7. Если тесты упали — переключись на скилл `debugging.md`.
