# Скилл: Добавление нового API-эндпоинта

Используй, когда нужно добавить новый роут в существующее FastAPI-приложение.

## Правила
- Следуй слоистой архитектуре (API -> Service -> Repo).
- Не пиши SQL-запросы в роутере.

## Алгоритм
1. **Схемы**: В `src/schemas/` создай Pydantic-модели для запроса (`XxxCreate`) и ответа (`XxxResponse`).
2. **Репозиторий**: В `src/repos/` добавь методы работы с БД (если их нет).
3. **Сервис**: В `src/services/` напиши бизнес-логику.
4. **Роутер**: В `src/api/` создай `APIRouter` (или добавь в существующий).
   - Обязательно используй `response_model=XxxResponse`.
   - Добавь `status_code` (201 для создания, 404 для not found).
5. **Подключение**: В `src/main.py` проверь, что роутер подключен через `app.include_router()`.
6. **Проверка**: Напиши тест на новый эндпоинт и запусти его.
