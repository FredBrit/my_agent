# Скилл: Рефакторинг

Используй, когда просят улучшить код, разбить большую функцию или переименовать переменные.

## Правила
- НЕ меняй поведение кода (все тесты должны остаться зелёными).
- Делай маленькие шаги. Один коммит = одно изменение.

## Алгоритм
1. **Защита**: Убедись, что есть тесты. Запусти их (`run_command("python -m pytest")`). Если тестов нет — напиши их сначала (скилл `testing.md`).
2. **Поиск**: Используй `search_in_files`, чтобы найти все места использования старого кода/имени.
3. **Изменение**: Вноси правки через `edit_file`.
4. **Проверка**: После каждого шага запускай тесты. Если упало — откати шаг (сделай `edit_file` в обратную сторону) и попробуй иначе.
