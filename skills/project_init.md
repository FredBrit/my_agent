# Скилл: Создание нового проекта с нуля

Используй, когда пользователь просит «создай новый проект» или «инициализируй приложение».

## Алгоритм
1. Создай структуру папок (через `write_file` в файл `.gitkeep` внутри папки): `src/`, `tests/`, `src/api/`, `src/models/`, `src/schemas/`.
2. Создай `requirements.txt` с базовыми зависимостями (`fastapi`, `uvicorn`, `pytest`, `sqlalchemy`, `pydantic`).
3. Создай `src/main.py` (точку входа) с базовым `FastAPI()` и проверкой `/health`.
4. Создай `src/config.py` (настройки).
5. Создай `README.md` с инструкцией запуска.
6. Установи зависимости через `install_package`.
7. Запусти `run_command("python -m pytest")`, чтобы убедиться, что всё работает (даже если тестов 0, он не должен падать с ошибкой импорта).
